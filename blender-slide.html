02 / CORE TECHNOLOGY

中核は Model Context Protocol (MCP)

MCP とは

AI アシスタントと外部ツール / データを 標準化された JSON-RPC で接続するためのオープン仕様。
「LLM ↔ 任意のアプリ」の繋ぎ込みを毎回作らず、サーバを一度書けば 任意の MCP クライアントから利用できる。

  • 1 MCP Host / Client
    Claude Code・Claude Desktop・Cursor など。LLM 側の実行環境。
  • 2 MCP Server
    ツール (function) を公開する側。今回の blender-mcp はここ。
  • 3 Transport
    stdio もしくは HTTP/SSE。Claude Code はローカル stdio が基本。
KEY IDEA

「USB-C」のように
差し替え可能な接続層

Blender 用に書かれた MCP サーバは、そのまま Cursor からも Claude Desktop からも呼べる。クライアントごとの個別実装が不要になり、 ツール側 (Blender) は「一度だけ」公開すれば良い。

04 / CAPABILITIES

できること & セットアップ

Claude Code 経由でできる主な操作

シーン・オブジェクト検査

シーン階層、選択中オブジェクトの座標・属性を取得。

オブジェクト操作

プリミティブ生成、移動・回転・スケール・複製・削除。

マテリアル制御

ノードグラフ経由で色・粗さ・テクスチャを設定。

任意 Python の実行

bpy を使った任意スクリプトを Blender 内で実行。

セットアップ手順

1Blender アドオンを導入
addon.py を Blender に追加し、N パネルから Server を起動。
2Claude Code に登録
下記コマンド一発で MCP サーバを登録。
3対話で操作
「立方体を 10 個並べて」などの自然言語で操作開始。
$claude mcp add blender uvx blender-mcp
※ uv (uvx) のインストールが前提。Blender 3.x / 4.x で動作確認実績あり。

05 / SUMMARY

3 つの要点

01

実現は 2025 年春

MCP (2024.11) → Claude Code (2025.02) → blender-mcp (2025.03) の流れで一気に整った。

02

鍵は MCP

標準化されたツール接続層により、「Claude が Blender を呼ぶ」が個別実装なしで成立。

03

実体は TCP ブリッジ

MCP サーバが stdio ⇄ TCP:9876 を変換し、Blender アドオンがメインスレッドで bpy を実行。
